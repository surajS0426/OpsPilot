# New starter missing system access

runbook_id: new-starter-access
category: access

## Symptoms
A new starter cannot open one or more systems their role needs, such as a team file share. They can sign in to their laptop, but see "access denied" or the application is missing.

## First checks
1. Confirm the start date and that the line manager approved the joiner request.
2. Compare the user's access with a colleague in the same role.
3. For finance-system access, confirm the system owner has also approved it.

## Fix
1. If the access was never requested, ask the line manager to submit an access request.
2. If an application is missing, push the install with the device-management tool.
3. Ask the user to sign out and back in; approved access can take 30 minutes.
4. Confirm each system opens.

## Escalate when
- Several new starters in one team have no access: escalate to identity as P2.
- Approved access still missing: assign to the identity queue as P3 if the person cannot work, or P4 if not.
- Admin or finance-system access: assign to the identity queue at the same priority. Finance access needs system-owner approval first.
