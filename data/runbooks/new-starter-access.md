# New starter missing system access

runbook_id: new-starter-access
category: access

## Symptoms
A new starter cannot open one or more systems their role needs, such as the HR portal or a team file share. They can sign in to their laptop, but see "access denied" or the application is missing.

## First checks
1. Confirm the start date and that the line manager approved the joiner request.
2. Compare the user's access groups with a colleague in the same role.
3. Confirm the user has signed out and back in since any changes.

## Fix
1. If the approved request lists the access, add the user to the missing groups.
2. If never requested, the line manager must request it in the self-service portal.
3. Ask the user to sign out and back in; new access can take 30 minutes.
4. Confirm each system opens.

## Escalate when
- Several new starters in one team have no access: escalate to identity as P2.
- One person cannot work at all after all fix steps: assign to the identity queue as P3.
- One person missing a system they do not need yet: assign to the identity queue as P4.
