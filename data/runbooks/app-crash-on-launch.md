# Application crashes on launch

runbook_id: app-crash-on-launch
category: software

## Symptoms
An application closes or shows an error as soon as the user opens it, before they can use it. Other applications on the laptop work normally.

## First checks
1. Note the exact error message and the application's version.
2. Ask whether it started after an update or restart, and whether colleagues are affected.
3. Check the laptop has at least 10 GB of free disk space.

## Fix
1. Restart the laptop and try again.
2. Install pending updates from the self-service portal so the application is version 8.3 or later.
3. Repair or reinstall the application through the self-service portal.
4. If it still crashes, test with a different user account on the same laptop to see whether the problem is user-specific.

## Escalate when
- Many users crash after the same update: escalate to desktop-support as P1.
- One team cannot open an application they need: escalate to desktop-support as P2.
- One person still crashing after all fix steps: assign to the desktop-support queue as P3.
