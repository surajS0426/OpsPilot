# Request to install software

runbook_id: software-install-request
category: software

## Symptoms
The user wants a new application on their laptop but cannot install it themselves, because they do not have administrator rights or the installer is blocked. Nothing is broken; this is a request for new software.

## First checks
1. Check the software catalogue to see whether the application is approved.
2. Confirm the business reason and the line manager's approval.
3. Check the laptop meets the application's requirements.

## Fix
1. If approved, guide the user to install it from the self-service portal; if they cannot, push the install with the device-management tool.
2. If not approved, raise a software request with the manager's approval attached.
3. Never give the user administrator rights or install from a downloaded file.
4. Confirm the application opens after installation.

## Escalate when
- The application is not in the software catalogue and needs approval or packaging: assign to the desktop-support queue as P4.
- The software comes from an unknown website or supplier: assign to the security queue as P4.
- A whole team needs the software for a deadline: assign to the desktop-support queue as P3.
