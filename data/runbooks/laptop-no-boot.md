# Laptop will not power on or boot

runbook_id: laptop-no-boot
category: hardware

## Symptoms
The laptop does not turn on when the power button is pressed, or it starts but stops on a black screen, logo or error message and never reaches the sign-in screen. The user cannot use it at all.

## First checks
1. Check the charger light and connect a known-working charger for 15 minutes.
2. Ask whether there are any lights, fan noise or beeps when powering on.
3. Ask about recent drops, spills or updates.

## Fix
1. Unplug all accessories and the docking station, leaving only the charger.
2. Hold the power button for 30 seconds to force a shutdown, then power on.
3. If a recovery screen appears, choose "Startup repair".
4. Connect an external monitor to check whether only the screen has failed.

## Escalate when
- Laptop still does not start after all fix steps: assign to the desktop-support queue as P3 and arrange a loan laptop.
- Liquid damage or a burning smell: unplug it and assign to the desktop-support queue as P3.
- Several laptops in one team fail after the same update: escalate to desktop-support as P2.
